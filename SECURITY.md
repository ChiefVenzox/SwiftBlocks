# Security Policy

## Supported Versions

SwiftBlocks is in early development. Security fixes are applied to the default branch first.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| tagged releases | After the first stable release |

## Reporting a Vulnerability

Please report security issues privately instead of opening a public issue.

Send a report to the repository owner with:

- a concise description of the vulnerability
- affected files, APIs, or versions
- reproduction steps or proof of concept
- expected impact
- any suggested fix, if available

## Scope

Security reports are welcome for:

- unsafe generated SwiftUI output
- data loss in serialized design documents
- package supply-chain or dependency risks
- crashes caused by malformed imported documents

Out of scope:

- purely visual layout bugs
- feature requests
- issues requiring physical access to an unlocked development machine

## Response

The project aims to acknowledge valid reports within 7 days and publish fixes as soon as practical.
