# Roadmap

## Short term

- Generate SwiftUI code from `EDKDesignDocument`
- Add Foundation Models-backed Auto Craft on iOS 26/macOS 26 while keeping the deterministic local engine as a fallback
- Add text editing in the inspector
- Add padding, alignment, and typography controls
- Add more base components: input, badge, alert, segmented control, toolbar

## Medium term

- Nested layouts for true HStack/VStack composition
- Save and load design documents
- Component presets and reusable templates
- Snapshot tests for generated SwiftUI output

## Long term

- Visual constraint editing
- Design token export
- Figma import/export experiments
- Package plugin or companion app for a richer builder workflow
